## 各文件是什么

### 00_任务与回复：日常写作

| 文件 | 用途 |
|---|---|
| `论文.md` | 三位审稿人的原始意见、翻译和整体应对方案，用于核对问题；不是最新回复稿 |
| `反驳草稿.md` | 你负责的FC8s W1/W2/Q3及HFLj W2回复，含英文正文与中文说明；日常修改这一份 |
| `检查补全清单.md` | 已完成内容、真实缺口、修复记录及验证结果 |

### 01_论文源码：原文基准（当前冻结）

`ICLR2027_ScienceDoc/` 是完整工程：`iclr2027_conference.tex` 为主文件；`.bib` 为参考文献；`.sty/.bst` 为模板与文献样式；`math_commands.tex` 为数学命令；其余图片目录是论文插图。当前仅用于查阅，暂不编辑主文件、模板或图片；待你明确要求后再进行论文修改。

### 02_学科统计：W1回复的数据依据

| 文件 | 用途 |
|---|---|
| `学科统计结果.txt` | 易读的统计输出。包含历史未校正检验和新增Holm校正；解释以校正结果及限制说明为准 |
| `学科置信区间.json` | 各模型、学科的正确题数及Wilson置信区间，供程序读取 |
| `table3_with_ci.tex` | 带置信区间的LaTeX表格片段，可合入论文；不是独立可编译的论文 |
| `多重比较校正.json` | 88次比较的原始p值和Holm校正p值；校正后12项显著 |
| `领域合并映射_61到52.csv` | 暂缓方案：旧领域到拟议新领域的映射，未采纳 |
| `2200题领域合并对照.csv` | 暂缓方案的逐题对照，两题缺口保留为备注，本轮不推进 |
| `200篇结构化论文_合并领域索引.csv` | 暂缓方案的200篇对照，不替换原manifest分类 |

### 03_Judge一致性标注：真实实验与模拟预览

| 文件 | 用途与使用方式 |
|---|---|
| `专家A标注表.xlsx`、`专家B标注表.xlsx` | 分别交给两位标注者，独立填写“标注”列；两份内容相同、顺序不同，靠编号对齐 |

| `判定答案键_勿外发.csv` | 编号到模型/Judge判定的映射，仅供组织者分析，不能发给盲标者 |
| `抽样分布核对.md` | 2,000条样本相对23,789条有效判定的分布核对 |
| `真实标注进度与Judge统计.md` | 当前真实标注进度及11模型已有Judge准确率，人工一致性仍未计算 |
| `真实标注进度与Judge统计.json` | 上述审计结果的程序版本 |
| `模拟预览_非真实实验/模拟一致性预览_非真实实验.xlsx` | 模拟结果总表及2,000条模拟标签，用于查看展示效果 |
| `模拟预览_非真实实验/模拟结果与回复效果预览.md` | 模拟表格和明确标注为模拟的英文段落 |

**统计口径：** 论文Judge按CORRECT / INCORRECT描述；准备表及结果包的三档记录仅在分析时映射为二分类，原始记录不改写。主表Spearman ρ比较11个模型的准确率排名；Cohen’s κ比较2,000个回答的逐条判定。2,000条回答涉及1,349道不同问题。模拟结果不能填写进真实专家表或正式实验结论。

### 06_200篇结构化论文：查论文与结构化内容

先打开 `manifest.csv` 按标题、学科、领域或arXiv编号找论文；字段解释见 `说明.md`。8个学科目录中的每篇均包含：

| 文件/目录 | 内容 |
|---|---|
| `paper.pdf` | 论文PDF |
| `source/` | 原始LaTeX源码和图片 |
| `main_flat.tex` | 展开引用后的单文件LaTeX |
| `structured.json` | 标题、摘要、章节、图、表、公式及计数 |
| `meta.json` | arXiv编号、作者、日期、学科、领域和文件统计 |

这200篇是另行下载的结构化材料，不自动等同于原基准693篇的结构化输入实验。

`代码/README_脚本使用.md` 列出每个脚本的功能、依赖和命令。`node_modules` 是本机共享依赖的链接，不是数据集，不必作为研究材料打包。

## 最常用的三个操作

### 1. 看效果和写回复

打开模拟Excel查看格式，再编辑 `00_任务与回复/反驳草稿.md`。当前可修改论述和引用；真实人工结果要等标注完成后再填写。只有确认事实和占位符全部补齐后，才形成提交版。

### 2. 开始真实标注

分别把A表、B表及标注规则交给两位标注者，保留答案键。两人独立完成“正确/部分正确/错误”三选一，不看模拟标签。收回时先备份原文件，再将完成版本放回原路径。不要重新抽样覆盖已标注的文件。

在本目录打开终端，标注完整后运行：

```bash
cd /Users/chenzijian/Downloads/rebuttal
python3 -B 代码/judge_audit_analysis.py \
  03_Judge一致性标注/判定答案键_勿外发.csv \
  03_Judge一致性标注/专家A标注表.xlsx \
  03_Judge一致性标注/专家B标注表.xlsx \
  03_Judge一致性标注/一致性结果
```

生成 `一致性结果.md` 和 `一致性结果.json`。目前表格为空，运行会提示缺标，这是预期行为。脚本的置信区间是行级bootstrap初步结果，正式推断还应考虑问题/文档聚类；不能仅凭区间重叠断言与人类等效。

### 3. 检查200篇文件是否齐全

```bash
python3 -B -I 代码/verify_structured.py 06_200篇结构化论文
```

会核对配额、重复项和必要文件，并重新生成 `manifest.csv`；不会重新下载论文。其余重算和模拟重建操作见脚本使用说明。
