## 3. Reviewer FC8s — Q3（拼接 PDF 是否保留格式、是否构成人为线索）

**Question (Q) 3:**

Thanks for the question. **Yes, the concatenated evaluation PDFs retain the original formatting of each source document.** As described in Appendix A.3, two or three source PDFs are concatenated in a fixed order *without changing the content of their pages*. Each source document therefore keeps its own title page, headers, layout, and fonts. We consider this retained formatting a natural property of the task rather than an artificial cue, for four reasons.

1. **Models only see rendered page images, not PDF metadata.** Every page is rendered at 144 DPI and supplied as an image preceded by an external `[PDF_PAGE_N]` label (Appendix C.1). File-level metadata of the original PDFs (bookmarks, document properties, file names, embedded outlines) is not visible to the models. The only boundary information available is the visible page content itself, exactly what a human reader sees.
2. **Visible document boundaries reflect realistic multi-document reading.** When researchers compare or combine findings across papers, each paper is naturally recognisable by its own title page and layout. Hiding these boundaries would make the input less realistic rather than more rigorous.
3. **Knowing the boundaries does not reveal the answer.** Every Multi-Document question passes a per-source ablation (Section 3.3, Appendix A.10): removing any source document makes part of the answer unsupported. Knowing where one document ends therefore does not tell the model *which* pages within each document contain the required evidence or *how* to integrate it. Evidence is also scored on page indices of the merged PDF, so boundary knowledge alone gives no evidence-localization credit.
4. **Observed difficulty does not eliminate the need to test shortcuts.** Multi-Document QA remains the hardest task even with the boundaries visible: 7 of the 11 models score below 50% (Table 2). Our case studies (e.g., Case 3) show failures caused by confusing *which* source supports *which* part of the answer, even though the documents are clearly separated. This shows that the task remains difficult, but does not by itself rule out benefits from boundary cues. We therefore avoid claiming that the current results constitute a controlled shortcut ablation.

We will clarify these points in Appendix A.3 of the revision.

**Capabilities and failure modes revealed beyond M3SciQA.** These design differences support complementary diagnostics, several of which are not part of M3SciQA’s reported evaluation:
