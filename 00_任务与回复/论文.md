## 1. 审稿意见原文与中文翻译

### 1.1 Reviewer pgLa（Rating 2 / Confidence 4）

#### 英文原文

**Paper Summary:**
ScienceDoc evaluates question answering over scientific documents using 2,200 questions from 693 documents across eight disciplines. It includes General, Unanswerable, Reasoning, and Multi-Document tasks, with reference answers and page-level evidence annotations. The evaluation provides PDF pages as images to 11 multimodal models and scores answer correctness and evidence selection separately. The results show variation across tasks and disciplines, particularly in abstention and evidence localization.

**Presentation:** 3: Clear and easy to follow.
**Informativeness:** 2: I learned something interesting or useful.
**Soundness:** 2: I have minor or fixable concerns about the paper's soundness.

**Critical Strengths:**
S1. The dataset covers eight disciplines and includes questions about both single and multiple documents, providing material for comparing model performance across scientific documents. The answer and evidence-page annotations allow subsequent studies to compare answering and evidence selection on the same questions without reconstructing these annotations.
S2. The paper checks both whether a model answers correctly and whether its cited pages match the annotations. This reveals problems that overall accuracy can hide: a model can answer correctly but cite the wrong pages, or perform well on answerable questions but struggle to abstain when information is missing. These distinctions make the evaluation more informative.
S3. The paper is well written. The presentation is clear and easy to follow.

**Critical Weaknesses:**
W1. The paper does not clearly explain what this benchmark measures beyond existing work. The introduction emphasizes disciplinary differences, evidence support, and reasoning across documents, then interprets the results as weaknesses in these capabilities (pp. 1–2). The analysis mainly reports score differences across models, tasks, and disciplines, without showing which errors arise from scientific content and which reflect problems common to long-document QA. Table 1 lists benchmark features but does not compare the cited M3SciQA, which appears closely related from the description in this paper. Readers therefore see a new set of evaluation results, but it remains unclear what they learn beyond existing scientific-document QA benchmarks.
W2. The experiments do not show where the models struggle. The authors render PDF pages as images, so models must read the pages and locate information before answering. The resulting scores reflect both the input format and the demands of the questions. I could not find results comparing this setup with structured text and tables alongside retained figures, or with retrieval followed by answering over the same documents. Appendix C.4 lists full, oracle, and qa-field page-selection modes, but does not specify the settings used for each model in the main table or clearly report performance with only gold evidence pages. Without these comparisons, it is difficult to tell whether models struggle to answer the scientific questions or to read and locate the information in the supplied input.
W3. The evidence-page evaluation has a related problem. The pages a model lists at the end do not establish which pages it used to answer: if other pages were available, the answer could draw on information that was not cited. The current page-level metrics check agreement with annotations, but do not test whether the citations provide enough evidence for the answer. If the model answers again in a fresh context containing only its cited pages, does it retain the original accuracy? This would help assess whether the declared evidence is sufficient. Even unchanged accuracy would not establish that the first answer actually relied on those pages.

**Questions For Authors:**
Q1. What specific capability does ScienceDoc add to the evaluation provided by existing scientific-document QA benchmarks? Please clarify the distinction from M3SciQA and identify the results that support the interpretation of the observed errors as limitations in scientific understanding or reasoning.
Q2. For each model in the main table, which page-selection policy, page limit, resizing or tiling settings, and overflow handling were used? Were all selected images supplied in one request? Are there results using structured text and tables with retained figures, or retrieval over the same documents? Such comparisons would help determine how strongly the conclusions depend on the chosen input pipeline; their document coverage, parsing losses, and computational budgets should be specified.
Q3. Was the listed oracle policy evaluated? For the same answerable questions, what are the answer accuracies with full-document inputs and gold-evidence-page inputs, broken down by task and model? A large gap would indicate a substantial contribution from evidence selection or input burden. Remaining errors would still require separating within-page perception from understanding and reasoning. Unanswerable questions should be treated separately because providing empty gold evidence changes the task.

**Flag For Ethics Review:** No
**Rating:** 2: Weak rejection
**Confidence:** 4: I have substantial direct research experience on this topic.

### 1.2 Reviewer FC8s（Rating 2 / Confidence 3）

#### 英文原文

**Paper Summary:**
This paper introduces ScienceDoc, an evidence-grounded, multidisciplinary, and multimodal question answering (QA) benchmark for scientific documents. The dataset consists of 2,200 QA pairs derived from 693 source documents, spanning 8 major disciplines and 61 fine-grained scientific fields. The benchmark is uniquely structured to include 4 task types: General, Reasoning, Multi-Document, and Unanswerable questions. A key feature of ScienceDoc is its hierarchical evaluation, which assesses both the semantic correctness of the answer and the model's ability to precisely locate the supporting evidence pages. The authors evaluate 11 representative Multimodal Large Language Models (MLLMs), finding that while models can achieve high answer accuracy, their evidence localization (Evidence F1) often lags significantly behind, and tasks like multi-document integration and unanswerable question detection remain highly challenging.

**Presentation:** 3: Clear and easy to follow.
**Informativeness:** 3: I gained a substantially deeper understanding of the problem or question.
**Soundness:** 2: I have minor or fixable concerns about the paper's soundness.

**Critical Strengths:**
1. Separation of Answer Accuracy and Evidence Grounding: The benchmark makes a highly consequential contribution by evaluating evidence localization (E-Precision, E-Recall, E-F1) alongside standard answer accuracy. The qualitative case studies brilliantly illustrate why this is necessary: for instance, a model like Qwen3-VL-4B can generate a semantically correct answer while indiscriminately citing all 51 pages of a document. This proves that relying solely on answer accuracy is insufficient for evaluating true document comprehension in scientific QA.
2. Robust Task Diversity Exposing MLLM Flaws: The inclusion of Multi-Document and Unanswerable tasks exposes critical weaknesses in state-of-the-art models. The finding that accuracy on unanswerable questions varies wildly from 2.50% (InternVL3.5-8B) to 91.00% (Claude Sonnet 5) provides an excellent, rigorous test of hallucination resistance and a model's ability to recognize insufficient evidence.

**Critical Weaknesses:**
1. Misalignment Between Claimed Diversity and Actual Dataset Scale: The paper strongly promotes its broad coverage of 8 disciplines and 61 scientific fields. However, the total dataset size is only 2,200 questions. This results in a very sparse distribution of questions across these fine-grained fields. For example, the entire Quantitative Finance domain contains only 86 questions, and Quantitative Biology contains only 114. Drawing definitive conclusions about a model's domain-specific strengths and weaknesses (as attempted in Table 3 and Figure 5b) is statistically fragile with such small sample sizes per field.
2. Unvalidated Reliability of LLM-as-a-Judge for Niche Science: The semantic correctness of the free-form answers is evaluated using an LLM-as-a-Judge approach (prompting a model to output CORRECT/INCORRECT). Given the highly specialized, multidisciplinary nature of the dataset—which includes complex equations, physics thresholds, and quantitative biology metrics—relying on an LLM to accurately judge semantic equivalence without a reported human-agreement validation study is a significant methodological risk. False positives or false negatives by the judge model could easily skew the benchmark results.

**Questions For Authors:**
1. Given the sparse distribution of questions in certain disciplines (e.g., only 86 questions for Quantitative Finance), how statistically significant are the domain-specific performance variations reported in Table 3 and Figure 5b? Would you consider aggregating some of these fields or adding confidence intervals to the domain-specific breakdown to prevent over-interpretation of the results?
2. How did you validate the reliability of the LLM-as-a-Judge? Did you conduct a human-annotator agreement study on a subset of the judge's outputs to ensure it accurately assesses semantic equivalence for highly complex, mathematically heavy, or discipline-specific answers? If so, what was the agreement rate?
2. [原文编号如此，实为第 3 问] For the multi-document task, do the concatenated PDFs retain the formatting and metadata of the original separate PDFs in a way that might provide artificial cues to the models regarding document boundaries?

**Details Of Ethics Concerns:** none

## 4. 补充实验清单

按 **优先级（P0 必做 / P1 强烈建议 / P2 时间允许）** 排列。"模型子集"指为控制成本选取的代表模型，建议：**Qwen3-VL-8B、InternVL3.5-8B、Gemma 3 27B、GLM-4.6V、DeepSeek-V4-Flash、Claude Sonnet 5**（覆盖小/大、开源/闭源、高/低分）。

### P0-1 输入条件拆解实验（回应 pgLa W2/Q2/Q3、HFLj W3）—— **最重要**

**目的：** 把误差拆成"阅读/定位负担"、"页面内感知"、"科学理解与推理"三部分。

| 设置 | 输入 | 说明 |
|---|---|---|
| **Full-Image**（主表现有设置） | 全部 PDF 页面图像 | 需在论文中写清缩放和上限 |
| **Oracle-Image** | 只输入金标准证据页图像 | 用现有 `oracle` policy 即可，成本低（页数少） |
| **Oracle-Parsed** | 金标准页的结构化解析结果：文本 + LaTeX 公式 + Markdown/HTML 表格 + **保留图像** | 用 MinerU / Marker / Nougat 等解析工具；需报告解析损失（公式/表格解析失败率） |
| **Full-Parsed** | 全文结构化解析结果 + 保留图像 | 对应审稿人说的 "structured text and tables alongside retained figures" |
| **Retrieval-Image (top-k)** | 用视觉检索器（如 ColPali/ColQwen）或 BM25（基于解析文本）检索 top-k 页（k=3/5），再输入页面图像 | 对应 "retrieval followed by answering"；同时报告检索 Recall@k |

**分析方法：**
- `Full → Oracle` 的准确率提升 = **证据选择/输入负担**带来的损失；
- `Oracle-Image → Oracle-Parsed` 的差异 = **页面内感知**（OCR、公式、表格识别）带来的损失；
- **Oracle-Parsed 下仍然答错的题** = 主要归因于**科学理解/推理**，对其做错误类型标注（见 P1-3）。
- 按任务（Gen / Rea / Multi-Doc）× 模型分别报告。
- **不可回答题单独处理**（pgLa 明确要求）：Oracle 不适用，改用"最相似干扰页"（例如检索器对该问题检索出的 top-k 页，或标注者在构建时记录的 "nearby statement" 所在页）作为输入，测试**聚焦上下文下的拒答能力**。

**预期与叙事：** 如果 Oracle 下准确率仍明显低于 100%，且 Multi-Doc/Reasoning、含公式题、Math 学科在 Oracle-Parsed 下仍然更难，就可以论证"难度不只是长文档读取问题，而是科学内容本身的问题"——这正是 pgLa 要的证据。如果 Full→Oracle 差距很大，也是有价值的发现（说明证据定位是瓶颈，恰好支撑我们评估证据定位的动机）。**两种结果都能讲成正面故事。**

**成本：** Oracle 系列页数少，开销远小于主实验；Parsed 需一次性解析 693 篇文档；Retrieval 需检索器推理。建议在模型子集上跑全部 2,000 道可回答题。
