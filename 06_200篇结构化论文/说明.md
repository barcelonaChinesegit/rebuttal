# 200 篇结构化论文说明

## 选文规则

- 按 ScienceDoc 693 篇文档的学科比例分配 200 篇：计算机科学 84、物理 37、数学 23、统计 19、定量生物 11、电子工程与系统科学 10、经济 9、定量金融 7。
- 每个学科再分配到论文图 3 列出的领域对应的 arXiv 分类，只取该分类为**主分类**的论文，按提交时间从新到旧取（实际入选论文的首次提交时间为 2025 年 11–12 月）。
- 筛选条件（对应论文 3.1 节的文档过滤）：有 LaTeX 源码；能找到包含 `\documentclass` 和 `\begin{document}` 的主文件；正文超过 1.5 万字符；至少 3 个章节；至少 1 个图或表。没有源码、下载失败或单篇超过 5 分钟未下完的论文自动跳过并换下一篇，因此不需要“PDF 转 LaTeX”。
- 论文正文是 arXiv 原文（英文），没有翻译。

## structured.json 字段

JSON 的字段名保持英文（方便程序读取），含义如下：

| 字段 | 含义 |
|---|---|
| `title` | 论文标题 |
| `abstract` | 摘要 |
| `sections` | 按章节切分的正文列表；每项含 `level`（section / subsection / subsubsection，第一项 preamble 为正文开头）、`title`（章节标题）、`text`（该章节正文 LaTeX，公式保留在正文中，图表已抽出） |
| `figures` | 图列表；每项含 `caption`（图注）、`label`（引用标签）、`images`（`source/` 下对应的图片文件路径，即保留的原图） |
| `tables` | 表列表；每项含 `caption`、`label`、`latex`（表格的 LaTeX 源码） |
| `equations` | 行间公式列表；每项含 `env`（公式环境名）、`latex`（公式 LaTeX） |
| `stats` | 统计：`n_sections` 章节数、`n_figures` 图数、`n_tables` 表数、`n_equations` 公式数、`n_chars` 正文字符数 |

## meta.json 字段

| 字段 | 含义 |
|---|---|
| `arxiv_id` | arXiv 编号（含版本号） |
| `title` / `authors` / `published` | 标题 / 作者 / 首次提交时间 |
| `discipline` / `field` / `arxiv_category` | 学科缩写 / 论文图 3 中的领域名 / arXiv 分类 |
| `main_tex` | 主 tex 文件名 |
| `n_source_files` / `pdf_bytes` | 源码文件数 / PDF 大小（字节） |
| `n_sections` 等 | 同 structured.json 的 `stats` |
| `source_type` | 来源类型，均为 arXiv LaTeX 源码 |
